# csv-reader-speed-01

Read broken CSV files faster: a dependency-free, single-pass CSV reader that returns exactly csv-reader 1.0.0's answers (`{columns, rows, errors}`) for every input — BOM drop, LF/CRLF record ends, stray CRs, quoted fields with doubled quotes, quote junk, unterminated quotes, and short/long row padding/cutting — at a fraction of the reference's CPU time. Pure Node.js stdlib, no dependencies.
